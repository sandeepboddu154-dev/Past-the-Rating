# Past The Rating

**Everything is built for a number. We show what happens past it.**
YouTube: [@pasttherating](https://youtube.com/@pasttherating)

This repo is the channel's operating system: strategy, scripts, production packages, brand assets and tracking.

| Folder | Contents |
|---|---|
| `STATUS.md` | **Start here.** Completed and pending tasks, daily log |
| `docs/` | Audit, niche research, competitors, brand, calendar, monetization, workflow |
| `production/shorts/` | Production-ready Shorts packages |
| `production/longform/` | Long-form scripts and production plans |
| `brand/src/` | HTML/SVG templates + renderer (`node brand/src/render.js`, needs Playwright + ffmpeg) |
| `brand/renders/` | Banner, thumbnails, Short covers, Rating Bar animation |
| `tracker/` | Monetization eligibility tracker (CSV) |
