# Credit Management Design (`budget.py`)

## 1. Context (verified)
- **ElevenLabs** is the only provider the pipeline calls today: TTS (`tts.py:7`), Music (`gen_audio.py:58`) and SFX (`gen_audio.py:66`). The key is injected by the session proxy on the personal environment "past-the-rating"; the value is never stored.
- Video_001 consumed **20,070 ElevenLabs credits** (production_report.md §6), the only calibration point available.
- **Higgsfield:** 0 credits; **vidIQ:** 4 credits (`STATUS.md:26`). The existing policy is no spend without explicit approval (`docs/07-workflow-and-qc.md:13`).
- **Veo** clips are generated by the user outside this system, so that spend can be recorded but not metered.
- Existing scripts have **no spend controls beyond caching**: `tts.py` retries 4 times (`tts.py:12-18`), `gen_audio.py` 3 times (`gen_audio.py:43-50`).

## 2. Files (repo root, committed, cross-project)
```
budget/providers.json   static: units, how to read the balance, rate table (with "verified": true/false)
budget/approvals.json   human-written approvals
budget/ledger.jsonl     append-only: estimate · approval_used · request · result · actual
```

### `providers.json`
```json
{
 "elevenlabs": {"unit": "credits", "balance_method": "GET /v1/user/subscription (character_count / character_limit)",
                "rates": {"tts_eleven_v4": {"per": "character", "credits": 1.0, "verified": false},
                          "music":         {"per": "second",    "credits": null, "verified": false},
                          "sfx":           {"per": "request",   "credits": null, "verified": false},
                          "forced_alignment": {"per": "second", "credits": null, "verified": false}},
                "auto_approve_below": 2000},
 "higgsfield": {"unit": "credits", "balance_method": "MCP balance", "estimate_method": "MCP estimate_video_cost / estimate_image_cost",
                "auto_approve_below": 0},

}
```
Rates marked `verified:false` are calibrated from measured balance deltas (§4) before they are trusted.

## 3. Lifecycle of a generation request

```
plan needs asset ─► budget.py estimate ─► (estimate ≤ auto threshold && provider allows) ? auto : NEED APPROVAL
                         │                                                          │
                         ▼                                                          ▼
                 ledger: estimate                                  human adds approvals.json entry
                                                                   {id, provider, max_credits, scope, expires}
                         └──────────────► budget.py run (wrapper) ◄─────────────────┘
                                             │ checks: approval valid · idempotency key unused · retry budget left
                                             ▼
                                   balance_before ─► provider call ─► balance_after
                                             ▼
                                   ledger: actual = before − after (or provider-reported cost)
```

### Estimates that can be computed exactly today
- **TTS:** replicate `tts.py`'s cache test (`sha1([text, voice])[:12]` vs the sidecar `hash`, `tts.py:37-40`). Sum the characters of the scenes that would *actually* be re-voiced. This turns "re-voice the film" into an exact number before anything runs.
- **Music / SFX:** the list of missing files exactly as `gen_audio.py:56,64` decides it (it skips existing files), multiplied by the seconds requested.
- **Higgsfield:** its own `estimate_*_cost` MCP tools.
- **Veo:** the user enters the cost; the ledger records it.

## 4. Approvals and controls

| Control | Rule |
|---|---|
| Approval required | Any video or image generation; any audio job above `auto_approve_below`; any re-voice of a whole film |
| Approval scope | `{provider, max_credits, project, scenes[], expires}`; consumed as jobs run; can't be exceeded |
| Local-first | The director proposes generation only after the R0–R5 ladder rejects every local option (`VISUAL_DIRECTOR_DESIGN.md` §3). The estimate shows the local alternative next to it |
| Idempotency | key = `sha1(provider, endpoint, canonical params)`. If a successful result exists in the ledger, return it and don't call again |
| Retries | Retry only transport errors (connection, 5xx, 429 with backoff), **at most 2**. Content failures (e.g. 4xx, policy refusals) are never auto-retried. A timeout **after the request was sent** counts as possibly charged: check the balance before any retry |
| Stop-loss | Abort the batch if actual spend exceeds 120% of the estimate |
| Recording | Every result is written with provider, endpoint, params hash, output path, sha256, credits, approval id and time. Failed attempts are recorded too, which the current system never does (audit §9) |

## 5. Backward compatibility
`budget.py` **wraps** rather than modifies. For example, `budget.py run elevenlabs-tts -- python3 Project_Files/tts.py …` estimates first, reads the balance, runs the unchanged script, reads the balance again and records the delta. Existing scripts keep working without the wrapper.

## 6. Reports
`budget.py report` shows the balance per provider, spend per project and per scene, estimate vs actual, and pending approvals. This report is the first thing to show you before any batch generation.
